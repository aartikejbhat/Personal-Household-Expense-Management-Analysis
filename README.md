# Personal Household Expense Management & Analysis

## 📌 Project Overview

This project focuses on analyzing household expense data to understand spending patterns, expense categories, and overall expenditure.

The project uses Python, SQL, PostgreSQL, and data visualization techniques to organize expense records and generate meaningful insights.

## 🎯 Objectives

- Analyze household spending patterns
- Identify major expense categories
- Calculate and compare expenses
- Understand average household expenditure
- Perform data analysis using Python and SQL
- Create meaningful data visualizations
- Develop skills in PostgreSQL and Power BI

## 📊 Dataset

The project uses household expense data stored in:

`data/Real_Expense_Data.xlsx`

The dataset contains household expense records used for analysis and visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- SQL
- PostgreSQL
- Microsoft Excel
- Matplotlib
- Seaborn
- Power BI

## 🔍 Analysis Performed

### Python Analysis

- Data loading
- Data cleaning
- Exploratory Data Analysis (EDA)
- Expense category analysis
- Average expense calculation
- Spending pattern analysis

### SQL & PostgreSQL

- Data querying
- SUM and AVG calculations
- GROUP BY analysis
- ORDER BY analysis
- Category-wise expense analysis

### Data Visualization

Visualizations are created using:

- Matplotlib
- Seaborn

The visualizations help understand expense categories and spending trends.

## 📈 Key Insights

The analysis focuses on identifying:

- Major household expense categories
- Average expenditure
- Category-wise spending patterns
- Higher and lower expense areas
- Overall household spending trends
